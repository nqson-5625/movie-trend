--------------------------------------------------------------------------------
1. SCRIPT KHỞI TẠO CẤU TRÚC HDFS: `init_hdfs_dirs.sh`
--------------------------------------------------------------------------------

Script này chạy sau khi cụm HDFS khởi động để tạo toàn bộ cây thư mục chuẩn.
Thực thi trực tiếp trong Pod NameNode thông qua `kubectl exec`:

```bash
#!/usr/bin/env bash
# init_hdfs_dirs.sh - Khởi tạo cây thư mục chuẩn cho dự án Movie-Trend
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
if [ -f "$SCRIPT_DIR/../.env" ]; then
    set -a; source "$SCRIPT_DIR/../.env"; set +a
elif [ -f "$SCRIPT_DIR/../../../.env" ]; then
    set -a; source "$SCRIPT_DIR/../../../.env"; set +a
fi

K8S_NAMESPACE=${K8S_NAMESPACE:-bigdata}
K8S_POD_NAME=${K8S_POD_NAME:-hdfs-namenode-0}

echo "=== [MODULE 03] KHỞI TẠO CẤU TRÚC THƯ MỤC TRÊN HDFS (Kubernetes) ==="

HDFS_INIT_COMMANDS=$(cat << 'EOF'
set -x

# 1. Tạo các thư mục Vùng Dữ liệu Thô (Raw Zone)
hdfs dfs -mkdir -p /raw/ratings
hdfs dfs -mkdir -p /raw/tmdb

# 2. Tạo các thư mục Vùng Cách ly Lỗi (Quarantine Zone)
hdfs dfs -mkdir -p /quarantine/movielens
hdfs dfs -mkdir -p /quarantine/tmdb

# 3. Tạo các thư mục Vùng Tham chiếu Chuẩn (Reference Zone)
hdfs dfs -mkdir -p /movies/ref/current

# 4. Tạo các thư mục Vùng Batch (Hadoop MapReduce)
hdfs dfs -mkdir -p /batch/movie_stats
hdfs dfs -mkdir -p /batch/movie_daily_stats
hdfs dfs -mkdir -p /batch/genre_daily_stats
hdfs dfs -mkdir -p /batch/_meta

# 5. Tạo thư mục tạm hệ thống
hdfs dfs -mkdir -p /tmp/hadoop-yarn

# 6. Phân quyền
hdfs dfs -chmod -R 755 /raw
hdfs dfs -chmod -R 755 /quarantine
hdfs dfs -chmod -R 755 /movies
hdfs dfs -chmod -R 777 /batch
hdfs dfs -chmod -R 777 /tmp

set +x
echo "=== KIỂM TRA DANH SÁCH THƯ MỤC ĐÃ TẠO ==="
hdfs dfs -ls /
hdfs dfs -ls /raw
hdfs dfs -ls /movies
hdfs dfs -ls /batch
EOF
)

echo "Thực thi trên Kubernetes Pod: $K8S_POD_NAME (Namespace: $K8S_NAMESPACE)"
echo "$HDFS_INIT_COMMANDS" | kubectl exec -i -n "$K8S_NAMESPACE" pod/"$K8S_POD_NAME" -- bash
```

Cách thực thi:
- Gọi qua Make: `make init`
- Hoặc gọi trực tiếp: `bash scripts/init_hdfs_dirs.sh`

--------------------------------------------------------------------------------
2. SCRIPT THỰC HIỆN BÀN GIAO BƯỚC 16 VỚI MODULE 01: `publish_reference.py`
--------------------------------------------------------------------------------

Script này giải quyết trọn vẹn điểm nghẽn "Bước 16: Chờ HDFS endpoint/path để publish 
reference". Script thực hiện:
- Kiểm tra tính sẵn sàng của cụm K8s (chẩn đoán lỗi Pod/SafeMode thân thiện).
- Đọc file `movie_reference.tsv` từ `data/prepared/reference/` (hoặc sample).
- Tính checksum SHA256 và đếm số dòng (9.743 dòng = 9.742 phim + 1 header).
- Sao chép vào NameNode Pod bằng `kubectl cp`.
- Tải lên HDFS version path: `/movies/ref/version=<ref_version>/movie_reference.tsv`.
- Xác nhận số dòng trên HDFS khớp 100% với file local.
- Cập nhật atomic sang canonical path: `/movies/ref/current/movie_reference.tsv`.

Cách thực thi:
- Gọi qua Make: `make publish-ref`
- Hoặc chạy script: `python scripts/publish_reference.py`

Canonical Entrypoint công bố:
- Trong cụm K8s: `hdfs://hdfs-namenode-svc.bigdata.svc.cluster.local:9000/movies/ref/current/movie_reference.tsv`
- Ngoài cụm (qua Port-forward): `hdfs://localhost:9000/movies/ref/current/movie_reference.tsv`

--------------------------------------------------------------------------------
3. SCRIPT BÀN GIAO VÀ KIỂM TRA CHO MODULE 04 (MAPREDUCE): `verify_mapreduce_handoff.sh`
--------------------------------------------------------------------------------

Script này giúp Đỗ Sơn (Module 04) kiểm tra xem HDFS đã sẵn sàng cung cấp input 
và nhận output chưa:
- Kiểm tra sự tồn tại của `/movies/ref/current/movie_reference.tsv`.
- Kiểm tra thư mục `/raw/ratings/`.
- Thử nghiệm quyền ghi vào `/batch/` (phải đạt quyền 777).

Cách thực thi:
- Gọi qua Make: `make verify-mr`
- Hoặc chạy script: `bash scripts/verify_mapreduce_handoff.sh`

--------------------------------------------------------------------------------
4. WORKFLOW MỘT CHẠM CHO NGƯỜI CHẠY CUỐI CÙNG (ONE-CLICK PIPELINE):
--------------------------------------------------------------------------------

Để người chạy cuối cùng không phải gọi từng lệnh đơn lẻ, chạy lệnh tổng hợp:
```bash
make pipeline
```
Lệnh này sẽ tự động: `up` -> `init` -> `publish-ref` -> `verify-mr`.
