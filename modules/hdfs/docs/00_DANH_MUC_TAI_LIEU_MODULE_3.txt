I. GIỚI THIỆU BỘ TÀI LIỆU
Bộ tài liệu này được xây dựng chuyên biệt cho Giang - người chịu trách nhiệm chính 
Module 03 (HDFS). Tài liệu bao quát từ phân tích kiến trúc, hợp đồng dữ liệu, thiết kế 
hệ thống lưu trữ, kế hoạch triển khai, hướng dẫn cài đặt thực tế, giải pháp sink dữ 
liệu từ Kafka, các kịch bản bàn giao (handoff) với các module khác, cho tới kiểm thử 
và xử lý sự cố vận hành.

II. DANH MỤC CÁC TÀI LIỆU TRONG THƯ MỤC:

1. 01_TONG_QUAN_VA_PHAN_TICH_YEU_CAU.txt
   - Mục đích: Định vị vai trò của Module 3 trong kiến trúc Lambda Architecture.
   - Nội dung: Ranh giới trách nhiệm, input/output, các giả định, ràng buộc tài nguyên 
     nghiêm ngặt (VM 8GB RAM).

2. 02_HOP_DONG_DU_LIEU_VA_GIAO_TIEP_MODULE_3.txt
   - Mục đích: Cụ thể hóa DATA_CONTRACT.md cho riêng HDFS.
   - Nội dung: Quy định chi tiết các đường dẫn Raw, Reference, Batch, Quarantine; 
     giao tiếp với Module 1 (Data Prep), Module 2 (Kafka), Module 4 (MapReduce).

3. 03_THIET_KE_KIEN_TRUC_LUU_TRU_VA_TAI_NGUYEN.txt
   - Mục đích: Thiết kế kỹ thuật tầng lưu trữ phân tán.
   - Nội dung: Cây thư mục HDFS, chiến lược phân vùng (partition theo event_time), 
     định dạng file, tính toán dung lượng, tối ưu JVM Heap cho NameNode và DataNode 
     để chạy mượt mà trên 8GB RAM.

4. 04_KE_HOACH_THUC_HIEN_VA_CHECKLIST_TIEN_DO.txt
   - Mục đích: Lộ trình triển khai theo từng giai đoạn và danh sách đầu việc (checklist).
   - Nội dung: Phân chia 7 giai đoạn thực hiện, tiêu chí hoàn thành Bước 16 (Handoff 
     với Module 1) và chuẩn bị cho Module 4/5.

5. 05_HUONG_DAN_CAI_DAT_DOCKER_VA_K8S.txt
   - Mục đích: Hướng dẫn cài đặt hạ tầng thực tế.
   - Nội dung: File cấu hình docker-compose.yml mẫu (1 NameNode + 2 DataNodes) tối ưu 
     RAM, cấu hình core-site.xml, hdfs-site.xml, và hướng dẫn triển khai trên K8s.

6. 06_GIAI_PHAP_KAFKA_TO_HDFS_SINK.txt
   - Mục đích: Giải quyết bài toán đưa dữ liệu từ Kafka vào HDFS (cầu nối Module 2 -> 3).
   - Nội dung: So sánh các giải pháp Sink; cung cấp mã nguồn Python Ingestion Daemon 
     hoàn chỉnh (nhẹ, tiết kiệm RAM, tự động partition theo ngày, xử lý quarantine).

7. 07_SCRIPTS_VA_KICH_BAN_BAN_GIAO_HANDOFF.txt
   - Mục đích: Các script tự động hóa phục vụ bàn giao và tích hợp.
   - Nội dung: Script tạo thư mục HDFS, script kiểm tra checksum & publish canonical 
     reference cho Module 1, script kiểm tra dữ liệu cho Module 4 MapReduce.

8. 08_KICH_BAN_KIEM_THU_ACCEPTANCE_TEST.txt
   - Mục đích: Kiểm thử nghiệm thu chức năng và hiệu năng của Module 3.
   - Nội dung: 7 Test Cases chi tiết (kiểm tra cluster, quyền, publish reference, 
     ghi raw partition, quarantine, kiểm tra MapReduce đọc dữ liệu, đo RAM/CPU).

9. 09_VAN_HANH_BAO_TRI_VA_XU_LY_SU_CO.txt
   - Mục đích: Cẩm nang vận hành và khắc phục sự cố (Troubleshooting Guide).
   - Nội dung: Xử lý NameNode Safe Mode, lỗi lệch ClusterID DataNode, lỗi WebHDFS, 
     backup metadata (fsimage, edits), giám sát disk & RAM.

III. HƯỚNG DẪN THỨ TỰ ĐỌC VÀ THỰC HIỆN:
- Bước 1: Đọc file 01 và 02 để nắm vững yêu cầu và hợp đồng dữ liệu.
- Bước 2: Đọc file 03 để hiểu thiết kế kiến trúc và thông số bộ nhớ.
- Bước 3: Xem file 04 để bám sát checklist tiến độ.
- Bước 4: Làm theo file 05 để dựng HDFS Cluster (dùng Docker Compose trước).
- Bước 5: Chạy các script trong file 07 để khởi tạo thư mục và sẵn sàng nhận dữ liệu.
- Bước 6: Phối hợp Module 1 thực hiện Bước 16 (Publish Reference) bằng file 07 & 08.
- Bước 7: Thiết lập Ingestion Sink theo file 06 khi Module 2 phát dữ liệu lên Kafka.
- Bước 8: Lưu file 09 làm tài liệu tra cứu khi gặp lỗi.
